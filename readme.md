# Загрузчик книг Флибусты

Программа получает каталог книг автора по OPDS и скачивает выбранные языки и форматы в текущую папку. Для работы нужен Python 3.10 или новее; сторонних пакетов нет.

## Использование

```bash
# Скачать книги по ссылке на автора или его числовому ID
python3 /home/user/work/flibusta/flibusta.py https://flibusta.is/a/10084

# Найти автора по имени
python3 /home/user/work/flibusta/flibusta.py -a "франсуа рабле"

# Выбрать языки и форматы
python3 /home/user/work/flibusta/flibusta.py -a "франсуа рабле" -l ru en -f fb2 pdf djvu

# Распаковать скачанные ZIP (по умолчанию они сохраняются как архивы)
python3 /home/user/work/flibusta/flibusta.py -x -a "франсуа рабле"

# Из папки с книгами автора: докачать отсутствующие, включая проверку подпапок
python3 /home/user/work/flibusta/flibusta.py -s -a "франсуа рабле"

# Повторить неудачные загрузки из журнала текущей папки
python3 /home/user/work/flibusta/flibusta.py -r
```

Книги и журнал `flibusta-downloads.json` сохраняются в **папке, из которой запущена команда**, а не рядом со скриптом. Настройки по умолчанию читаются из `flibusta.ini` рядом со скриптом; другой файл можно указать через `--config ПУТЬ`.

## Ключи

| Ключ | Действие |
| --- | --- |
| `-a ИМЯ` | Ищет автора по имени или синониму имени в каталоге. Точное совпадение имеет приоритет; при поиске по синониму используется основная страница автора. Если подходят несколько авторов, выводит их имена и URL по одному на строке и ничего не скачивает. |
| `-l ru en` | Скачивает только книги на перечисленных языках. По умолчанию `ru`. |
| `-f fb2 pdf djvu` | Скачивает перечисленные форматы, если они есть в каталоге. По умолчанию `fb2`. |
| `-s` | Сверяет каталог автора с файлами в текущей папке и всех обычных подпапках, затем скачивает недостающие книги. Требует ссылку, ID или `-a ИМЯ`. |
| `-r` | Повторяет записи `failed` и `pending` из журнала текущей папки. Запускается отдельно, без автора, `-s`, `-l` и `-f`. |
| `-x` | Распаковывает скачанные ZIP; по умолчанию архивы сохраняются как `.fb2.zip`, `.pdf.zip` и т. п. Можно применять с `-r`. |

В режиме `-s` файлы сопоставляются прежде всего по ID книги и формату в имени, например `Название [12345].fb2`. Для файлов без ID используется название и расширение; такое совпадение применяется, только если у автора нет нескольких книг с одинаковым названием и форматом. Учитываются также `.fb2.zip`, `.pdf.rar` и другие архивы с указанным форматом. Пустые файлы не считаются загруженными. Сверка работает и без журнала; если журнал исправен, новые попытки записываются в него, и их ошибки можно затем повторить через `-r`. Повреждённый журнал синхронизации не мешает и не перезаписывается.

Во время поиска, чтения каталога, проверки файлов и загрузки терминал показывает текущее действие со спиннером «дыхание». В оболочке Midnight Commander показываются обычные строки состояния: обновление одной строки может мешать переключению панелей через Ctrl-O. Книги загружаются параллельно. Для каждой новой книги в стандартный вывод печатается только имя файла; ошибки и итог выводятся отдельно. ZIP по умолчанию сохраняется архивом; `-x` извлекает из него книгу. При повторе через `-r` сохраняется выбор распаковки из журнала, а `-r -x` включает её для повторяемых загрузок. PDF/DJVU в RAR сохраняются как архивы. Существующие файлы не перезаписываются.

Ctrl-C отменяет ещё не начатые загрузки и завершает программу с кодом 130 без traceback. Уже выполняющиеся сетевые запросы могут дождаться ответа или своего таймаута. Незавершённые записи остаются в журнале со статусом `pending`; их можно повторить через `-r` либо сверить по файлам через `-s`.

## Настройки

```ini
[defaults]
languages = ru
formats = fb2

[site]
mirror = https://flibusta.is

[downloads]
workers = 4
extract_zip = no
```

`workers` задаёт число одновременных загрузок от 1 до 16. `extract_zip = no` отключает распаковку по умолчанию; `-x` включает её для конкретного запуска. При прямой ссылке используется её домен. Поиск `-a` выполняется на зеркале из настроек; если веб-поиск недоступен, программа пробует OPDS на том же домене, а для `flibusta.is` — также `flub.flibusta.is`. Временные сетевые ошибки повторяются до трёх раз. Доступность сайта и зеркал зависит от сети.
