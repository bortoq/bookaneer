# Bookaneer — загрузчик книг Флибусты

[![CI](https://github.com/bortoq/bookaneer/actions/workflows/ci.yml/badge.svg)](https://github.com/bortoq/bookaneer/actions/workflows/ci.yml)
![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-blue)

Программа получает каталог книг автора по OPDS и скачивает выбранные языки и форматы в текущую папку. Нужен Python 3.10 или новее.

```bash
git clone https://github.com/bortoq/bookaneer.git
cd bookaneer
python3 -m pip install -r requirements.txt
# Необязательно: создать короткую команду fli, если ~/bin есть в PATH
mkdir -p "$HOME/bin"
ln -s "$PWD/flibusta.py" "$HOME/bin/fli"
```

Запускайте `flibusta.py` из любой папки, куда хотите сохранить книги. В примерах ниже используется необязательная команда `fli`; без неё замените `fli` на `python3 /путь/к/bookaneer/flibusta.py`.

## Использование

```bash
# Скачать книги по ссылке на автора или его числовому ID
fli https://flibusta.is/a/10084

# Найти автора по имени
fli -a "франсуа рабле"

# Выбрать языки и форматы
fli -a "франсуа рабле" -l ru en -f fb2 pdf djvu

# Скачать все языки и все форматы, доступные в каталоге автора
fli -a "франсуа рабле" -l -f

# Распаковать скачанные ZIP (по умолчанию они сохраняются как архивы)
fli -x -a "франсуа рабле"

# Из папки с книгами автора: докачать отсутствующие, включая проверку подпапок
fli -s -a "франсуа рабле"

# Повторить неудачные загрузки из журнала текущей папки
fli -r
```

Книги и журнал SQLite `flibusta-downloads.sqlite3` сохраняются в **папке, из которой запущена команда**, а не рядом со скриптом. Настройки по умолчанию читаются из `flibusta.ini` рядом со скриптом; другой файл можно указать через `--config ПУТЬ`.

## Ключи

| Ключ | Действие |
| --- | --- |
| `URL` или `ID` | Страница автора вида `https://flibusta.is/a/2583` либо числовой ID автора. |
| `-a имя` | Ищет автора по имени или синониму. Точное совпадение имеет приоритет. Если подходят несколько авторов, выводит их имена и URL и ничего не скачивает. |
| `-l язык` | Скачивает книги на одном или нескольких указанных языках: `-l ru en`. Коды берутся из OPDS без закрытого списка. `-l` без значения выбирает все языки. По умолчанию `ru`. |
| `-f формат` | Скачивает один или несколько указанных форматов: `-f fb2 pdf`. Форматы берутся из доступных ссылок OPDS, включая исходные форматы книг. `-f` без значения выбирает все доступные форматы. По умолчанию `fb2`. |
| `-s` | Сверяет каталог автора с файлами в текущей папке и всех обычных подпапках, затем скачивает недостающие книги. Требует ссылку, ID или `-a ИМЯ`. |
| `-r` | Повторяет записи `failed` и `pending` из журнала текущей папки. Запускается отдельно, без автора, `-s`, `-l` и `-f`. |
| `-x` | Распаковывает ZIP с книгой внутри; по умолчанию такой архив сохраняется как `.fb2.zip`, `.pdf.zip` и т. п. EPUB, DOCX и другие форматы, устроенные как ZIP, сохраняются в своём формате. Можно применять с `-r`. |
| `--config файл` | Читает настройки из указанного INI-файла. |

На [странице поиска Флибусты](https://flibusta.is/book) перечислены, в частности, `doc`, `docx`, `chm`, `azw3`, `fb3`, `cbz`, `mp3` и другие исходные форматы. Программа получает доступные варианты из OPDS автора, поэтому ей не требуется фиксированный список форматов. Для конкретной книги скачиваются только варианты, для которых каталог даёт ссылку.

В режиме `-s` файлы сопоставляются прежде всего по ID книги и формату в имени, например `Название [12345].fb2`. Для файлов без ID используется название и расширение; такое совпадение применяется, только если у автора нет нескольких книг с одинаковым названием и форматом. Учитываются также `.fb2.zip`, `.pdf.rar` и другие архивы с указанным форматом. Пустые файлы не считаются загруженными. Сверка работает и без журнала; если журнал исправен, новые попытки записываются в него, и их ошибки можно затем повторить через `-r`. Повреждённый журнал синхронизации не мешает и не перезаписывается. Содержимое существующих файлов при `-s` не проверяется.

Во время поиска, чтения каталога, проверки файлов и загрузки терминал показывает текущее действие со спиннером «дыхание». В оболочке Midnight Commander показываются обычные строки состояния: обновление одной строки может мешать переключению панелей через Ctrl-O. Книги загружаются параллельно. Для каждой новой книги в стандартный вывод печатается только имя файла; ошибки и итог выводятся отдельно. ZIP по умолчанию сохраняется архивом; `-x` извлекает из него книгу. При повторе через `-r` сохраняется выбор распаковки из журнала, а `-r -x` включает её для повторяемых загрузок. PDF/DJVU в RAR сохраняются как архивы. Существующие файлы не перезаписываются.

Загрузка пишет данные по частям во временный файл и публикует книгу только после проверки. Для PDF, DJVU и FB2 проверяется начало файла; для ZIP с книгой внутри — структура архива и расширение файла. Размер сетевого ответа ограничен 512 МиБ, распакованной книги — 1 ГиБ. Ctrl-C отменяет ещё не начатые загрузки и завершает программу с кодом 130 без traceback. Уже выполняющиеся сетевые запросы могут дождаться ответа или своего таймаута. Незавершённые записи остаются в журнале со статусом `pending`; их можно повторить через `-r` либо сверить по файлам через `-s`.

## Настройки

```ini
[defaults]
languages = ru
formats = fb2

[site]
mirror = https://flibusta.is

[downloads]
workers = 4
extract_zip = no
```

`workers` задаёт число одновременных загрузок от 1 до 16. `extract_zip = no` отключает распаковку по умолчанию; `-x` включает её для конкретного запуска. При прямой ссылке используется её домен. Поиск `-a` выполняется на зеркале из настроек; если веб-поиск недоступен, программа пробует OPDS на том же домене, а для `flibusta.is` — также `flub.flibusta.is`. Временные сетевые ошибки повторяются до трёх раз. Доступность сайта и зеркал зависит от сети.

Код разделён на `fli_app/catalog.py` (поиск и OPDS), `transport.py` (HTTP), `files.py` (файлы), `journal.py` (SQLite), `ui.py` (статус) и `cli.py` (командная строка). Старый JSON-журнал не используется; `-r` читает только новый журнал SQLite.
