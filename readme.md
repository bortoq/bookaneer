# Загрузчик книг Флибусты

Программа скачивает книги автора по ссылке на его страницу (`/a/ID`), числовому ID или точному имени. Использует каталог OPDS Флибусты и сохраняет книги в текущую папку. Требуется Python 3.10+; сторонние пакеты не нужны.

```bash
python3 flibusta.py http://flibusta.is/a/2583
python3 flibusta.py "Артур Конан Дойль" -l ru en -f djvu pdf fb2
```

`-l` задаёт языки, `-f` — форматы. Значения по умолчанию (`ru`, `fb2`) и адрес зеркала задаются в `flibusta.ini`. Для поиска по имени используется зеркало из файла настроек; при прямой ссылке используется домен ссылки. При нескольких найденных авторах программа предложит указать ссылку `/a/ID`. Для другого файла настроек используйте `--config путь/к/flibusta.ini`.

ZIP с книгой распаковывается; PDF/DJVU в RAR сохраняются как архивы. Существующие файлы не перезаписываются. Книга скачивается только если каталог указывает её язык и соответствующий формат. Доступность сайта и зеркал зависит от сети.
